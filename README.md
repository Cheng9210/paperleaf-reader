# Paperleaf 論文閱讀室

Paperleaf 是一個瀏覽器內運作的論文閱讀介面。第一版提供 PDF 匯入、可拖曳雙欄版面、選字發音、螢光筆、文字註解、閱讀筆記，以及含註記 PDF／Markdown 筆記下載。

## 目前範圍

- 使用者匯入的 PDF 不會由網站上傳到伺服器。
- 筆記與註記依 PDF 內容識別碼儲存在目前瀏覽器；清除瀏覽器資料會移除它們。
- 初始論文、繁體中文譯文與查詞資料都是清楚標示的示範內容。
- 自訂 PDF 的自動翻譯、AI 閱讀分析與掃描 PDF OCR 尚未接入。
- 匯出的註記會固定在 PDF 頁面上，無法在其他閱讀器中當成獨立註記編輯。

## 本機使用

1. 執行 `pnpm install`。
2. 執行 `pnpm run prepare-assets`。
3. 執行 `pnpm run dev`，開啟畫面顯示的本機網址。

測試使用 `pnpm test`。
