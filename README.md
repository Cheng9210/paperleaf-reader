# Paperleaf 論文閱讀室

Paperleaf 是一個瀏覽器內運作的論文閱讀介面。提供 PDF 匯入、連續捲動、可拖曳雙欄、選字發音、可調色螢光筆、頁面文字註記、閱讀筆記，以及含註記 PDF／Markdown 筆記下載。

## 閱讀與註記

- 向下捲動即可接續下一頁；Ctrl＋滑鼠滾輪或觸控板捏合可縮放，點比例可恢復符合欄寬。
- 選字不開浮窗；示範詞彙只標記對應中文詞，Space 發音。
- 螢光筆以 Multiply 混色保留原文清晰度，可調顏色；單擊選取、雙擊刪除。
- T 工具以點擊處作為文字起點，靠近右側只縮短文字框，不改變起點。使用隨網站提供的 Noto Sans TC 黑體，可調顏色與 pt 字級、直接拖曳文字或把手移動、雙擊刪除。單擊可繼續編輯，Shift＋拖曳可選取註記文字。
- 縮放時保留已完成的頁面，等新畫布與選字層完成後一起替換。
- 復原按鈕可還原註記變更；PDF 匯出保留色彩與文字位置。

## 公開網址與資料

- GitHub Pages 版可直接開啟。第一次使用翻譯時，在「Gemini 設定」輸入自己的 Free Tier API 金鑰；它只存於當前瀏覽器，不會寫入 GitHub 儲存庫。每個瀏覽器需各自設定一次。
- 使用者匯入的 PDF 不會由網站上傳到 GitHub。翻譯時，擷取的論文文字會直接從瀏覽器送到 Google Gemini API。譯文與註記保存在當前瀏覽器；清除瀏覽器資料會移除它們。
- 請勿在共用電腦儲存個人金鑰。公開網頁中的瀏覽器端金鑰可能被該瀏覽器的擴充功能或其他可讀取頁面資料的程式取得。

## 目前範圍

- 筆記與註記依 PDF 內容識別碼儲存在目前瀏覽器；清除瀏覽器資料會移除它們。
- 初始論文、繁體中文譯文與詞彙對應都是清楚標示的示範內容；未建立對應的字詞不會改為整段標記。
- 自訂 PDF 可翻譯可擷取的英文文字；掃描 PDF 尚未接入 OCR。
- 匯出的註記會固定在 PDF 頁面上，無法在其他閱讀器中當成獨立註記編輯。

## 本機使用

1. 執行 `pnpm install`。
2. 執行 `pnpm run prepare-assets`。
3. 執行 `pnpm run dev`，開啟畫面顯示的本機網址。

測試使用 `pnpm test`。
