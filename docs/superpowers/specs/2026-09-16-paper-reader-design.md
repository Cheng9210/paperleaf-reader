# 論文閱讀輔助網站：介面第一版

## 目標與範圍

先完成可操作的桌面閱讀介面，介面文字使用繁體中文。不接雲端翻譯或 AI 分析服務，不要求 API 金鑰。示範翻譯與示範分析必須明確標示，不能冒充使用者上傳論文的結果。

## 方案選擇

- 靜態畫面：最快確認外觀，但無法驗證閱讀操作。
- 可操作介面搭配示範資料（建議）：可測試拖曳、選字、面板、筆記與註記，之後接入翻譯。
- 完整 AI 服務：需要服務選型、成本與金鑰設定，依使用者要求留待後續。

## 版面與閱讀流程

使用暖白紙張底色、深灰文字與低彩度綠色操作重點。上方工具列包含論文名稱、匯入 PDF、頁碼、縮放、註記工具、閱讀筆記及下載。

主畫面左邊保留 PDF 原始版面與可選取文字，右邊是翻譯段落。中間分隔線可用滑鼠拖動或鍵盤調整，有最小寬度限制。窄螢幕改為原文／翻譯頁籤。

初始示範論文提供事先配對的中英文內容。匯入使用者 PDF 後，原文正常顯示，右側顯示「尚未啟用翻譯」，不套用示範譯文。掃描 PDF 若沒有文字層，顯示無法選字的原因，OCR 留待後續。

## 選字與發音

選取原文文字後顯示浮窗，包含選取內容、詞義區與發音按鈕。示範論文提供示範詞義與譯文定位；自訂 PDF 顯示查詞尚未連接服務。以瀏覽器語音功能播放英文，無可用語音時明確提示。

有選字且焦點不在輸入欄時，空白鍵播放選字；正常筆記輸入不受影響。示範對齊優先標示詞語，無詞語配對時定位整句，不捏造精確對齊。

## 閱讀助手與筆記

按工具列按鈕才展開側面抽屜，可隨時收起。依使用者提供的「讀論文用.md」呈現：先說重點；論文架構（背景與文獻、目的、研究問題、研究目標、方法、結果、討論、結論）；值得質疑之處；簡單例子；如實整理。

每一部分都有可編輯筆記；支援將選取文字與頁碼加入筆記，點擊來源回到該頁。使用者 PDF 不自動生成分析；示範分析標示為示範。筆記在本機儲存，儲存失敗需提示，不宣称永久保存。

## 原文註記與匯出

提供選字螢光筆、頁面文字註解、刪除註記與復原操作。以 PDF 頁面座標儲存，縮放後仍對齊原文。以文件識別碼隔離不同論文的筆記與註記。

下載註記 PDF 時，將螢光筆與文字註解寫入輸出副本，原始檔不被改寫。匯出中文字須使用支援中文的字型。第一版允許註記扁平化，但介面須說明輸出的註記不可在其他閱讀器中當成獨立註記編輯。另提供筆記 Markdown 下載。

## 元件與資料流

將 PDF 載入與呈現、閱讀版面、選字浮窗、筆記面板、註記與匯出拆成獨立模組。共用文件識別碼、目前頁碼、選取範圍及頁面座標。未來翻譯服務透過段落識別碼回傳譯文及對齊資料，不與 PDF 顯示邏輯綁定。

## 錯誤與空白狀態

處理無效、損壞或加密 PDF；載入、匯出中的狀態；沒有文字層；語音不可用；本機儲存失敗。所有未接入服務的功能均明示狀態，不顯示假的成功結果。

## 驗收

驗證示範與自訂 PDF 顯示、雙欄拖曳與窄螢幕、選字浮窗、空白鍵發音不干擾輸入、筆記開關與來源跳轉、不同文件資料隔離、縮放後註記位置，以及下載 PDF 的中文註解與螢光筆。以實際畫面檢查閱讀空間與面板遮擋；以重新開啟輸出 PDF 驗證匯出結果。

## 後續階段

完成介面後，再用實際論文比較翻譯品質，接入上下文翻譯、術語表、查詞及有來源的閱讀分析。翻譯服務選擇、API 費用與 OCR 不屬於本階段。
