# Paperleaf 第一版驗證紀錄

驗證日期：2026-09-17

## 自動檢查

- 10 項核心測試通過：座標正規化、頁面範圍裁切、輸入欄空白鍵保護、PDF 座標轉換、文件識別碼、欄寬限制、Markdown 匯出、註記 PDF 匯出、旋轉／裁切頁面，以及不存在頁碼的保護。
- 應用程式與 PDF 模組通過 JavaScript 語法檢查。

## 實際畫面

- 桌面版顯示雙欄 PDF 與繁體中文示範譯文，原文保留文字層。
- 700 px 寬度下切換為「原文／翻譯」頁籤，筆記抽屜保持可用。
- 閱讀筆記依使用者提供的 Markdown 分成五組，論文架構內含八個子項目。
- WebMCP `read_paper_reader_state` 能讀取文件、頁碼、筆記與註記數量；`open_reading_notebook` 能開啟同一個可見筆記面板。

## PDF 匯出

- 以三頁示範 PDF 產生含螢光筆與繁體中文圖片註解的輸出。
- 重新開啟後仍為三頁、A4、未加密 PDF。
- 使用 Poppler 重新轉成圖片檢查，螢光筆與中文註解均可見、文字沒有方塊字或裁切。

## 已知範圍

- 翻譯、完整查詞與 AI 閱讀分析等候下一階段服務選型。
- 掃描 PDF 可顯示與加文字註解，但沒有 OCR，因此不能選字。
- PDF 與筆記都以瀏覽器裝置為界；網站不提供跨裝置同步。
