# Azure Translator F0 設定

1. 在 Azure 入口網站建立 **Translator 單一服務資源**，定價層選 **F0 免費層**。網站使用文字翻譯，無須購買文件翻譯。
2. 開啟資源的「金鑰與端點」，取得金鑰及區域；全域資源填 `global`，區域資源填入口網站提供的代碼。
3. 啟動本機網站，按翻譯欄的「Azure 設定」，填入金鑰及區域，確認 F0 後按「儲存並測試連線」。請勿把金鑰貼到聊天中。
4. 連線成功後關閉設定，匯入 PDF，按「翻譯全文」。可暫停／繼續，已完成的結果會快取。

官方建立資源說明：https://learn.microsoft.com/zh-tw/azure/ai-services/translator/how-to/create-translator-resource

金鑰存放在 `.local/azure.json`，不由網站提供下載，也不加入 Git。此檔未加密，請勿分享 `.local` 資料夾。翻譯快取及本機使用量也存放於此。

本機每月最多送出估計 200 萬字，不會自動切換付費方案。資源是否為 F0、其他應用的使用量及實際額度，以 Azure 入口網站為準。失敗請求與連線驗證也保守計入本機上限。

僅將擷取的英文論文文字送至 Azure，筆記及 PDF 檔案不會送出。掃描 PDF 尚需先做 OCR。詞語對應由 Azure 提供；無對應時不會任意框選整段。複雜雙欄、公式及表格的文字擷取可能需要人工核對。

## 驗證紀錄（2026-09-20）

自動測試涵蓋快取、金鑰隔離、來源限制、月額度保護、暫停／繼續、詞語對應及既有閱讀／註記回歸。Azure 回應使用測試替身，未使用真實金鑰。瀏覽器已確認設定表單、未設定提示、PDF 與原有筆記正常載入且無主控台錯誤。真實 Azure 連線仍需在設定表單完成驗證。
